## Release notes

### Core Spec 1.0

Core Spec 1.0 established the CIITR kernel as a formal boundary apparatus for structural comprehension claims. The release fixed the primitive axes $\Phi_i$ and $R_g$, null-point logic, admissibility discipline, negative evidence primacy, threshold architecture, instrumentation abstraction, thermodynamic constraint, and certification consequences.

### Core Spec 2.0

Core Spec 2.0 does not replace the original kernel. It hardens and extends it. The decisive additions are:

- attribution architecture as a kernel object
- communication surface as a multi-system analytical field
- negational control logic as a condition for disciplined back-inference
- invariance condition as the criterion for structural attribution
- clarification of the relation between binary admissibility, trivalent classification, and continuous metric
- threshold clarification for $\mathrm{MVR}$ and $\mathrm{Nash\text{-}CIITR}$
- instrumentation and certification updates required by the expanded kernel
